# NDB 医療圏ダッシュボード

厚生労働省「NDBオープンデータ」の医科診療行為（算定回数）を、都道府県・二次医療圏ごとに人口と組み合わせて可視化するサイトです。病院が自院の外部環境（地域の医療需要・提供状況）を把握し、投資判断の材料にすることを目的としています。

**公開サイト**：https://kntw-blip.github.io/ndb-iryoken-dashboard/

## できること
- 医科診療行為（約2,400分類・12,000コード）を検索し、分類単位またはコード単位で集計
- 全国／都道府県／二次医療圏ごとの年次推移（算定回数・人口・人口千人あたり）
- 地域比較（地図・ランキング・医療圏ごとの推移）と年齢調整比（SCR）
- 全国の性・年齢階級別の算定回数と算定率
- 将来推計（2025〜2050年、社人研推計人口ベース）
- 表示中のデータのCSVダウンロード、URLでの条件共有
- 初めての方向けの使い方ガイド（活用例・用語集・Q&A）、画面ツアー、各項目の「?」説明

## データと計算方法
サイト下部「データと計算方法」を参照してください。主な注意点：
- 集計は**医療機関所在地ベース**です（患者住所ベースではありません）。
- 年次比較のため全年度で**公費レセプトを含まない**集計を使用しています。
- 10未満は秘匿（‐）。医療圏別の値の多くが秘匿されている年度（入院系の項目では2018〜2021年度など）は自動で非表示にしています。

## 仕組み（毎月の自動確認・自動更新）
`.github/workflows/build.yml` が毎月2日 06:17（日本時間）に実行されます。

1. **公表状況の確認**（`scripts/fetch.py --check`）：厚労省のNDBオープンデータの各回のページ、総務省の住民基本台帳人口の公表ページを巡回し、公表ファイルの一覧から指紋（ハッシュ）を作成。公開中のサイトの `data/meta.json` と比べ、変化がなければ確認日時だけ記録して終了します。
2. **取得**（`scripts/fetch.py`、`scripts/geo.sh`）：変化があれば一次データをダウンロード。国土数値情報（医療圏データ）から市区町村→二次医療圏の対応表と簡略化した境界を作成。
3. **加工**（`scripts/build_ndb.py`、`scripts/build_pop.py`）：JSONに加工。対象期間が12か月に満たない回（部分公開）は除外。
4. **検証**（`scripts/pipeline.py validate`）：前回公開分と比べて、分類数の大幅な減少、過去年度の消失、主要項目の過去の全国値の2%以上の変化、二次医療圏の区分の変更、人口データの欠け、地図との不一致を確認。
5. **公開**：検証に合格した場合のみ `gh-pages` ブランチへ公開。
6. **通知**：GitHub の Issue で通知（【自動更新】反映した／【要確認】検証で問題があり保留した／【エラー】処理が失敗した）。

手動で実行する場合：Actions → build-and-publish → Run workflow（手動実行時は新しいデータがなくても再構築します）。
